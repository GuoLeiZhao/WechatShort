# 部署前必填配置

源码中所有密钥/凭证已替换为 `__占位符__`，交付方**不含任何真实密钥**。
部署前请把下列占位符替换为你自己申请的值。

## 一、`src/main/resources/` 配置文件

### application.yml（各平台小程序）
| 占位符 | 含义 | 从哪获取 |
|---|---|---|
| `__WX_APPID__` / `__WX_SECRET__` / `__WX_TOKEN__` / `__WX_AESKEY__` / `__WX_APPKEY__` | 微信小程序 app1（App 登录/播放器用） | 微信公众平台 |
| `__WX_OFA_APPID__` / `__WX_OFA_SECRET__` / `__WX_OFA_APPKEY__` | 微信公众号 app1gzh | 微信公众平台 |
| `__WX_APP2_APPID__` / `__WX_APP2_SECRET__` / `__WX_APP2_TOKEN__` / `__WX_APP2_AESKEY__` / `__WX_APP2_APPKEY__` | 第二个短剧小程序 app2（多租户，不用可删该条） | 微信公众平台 |
| `__DOUYIN_APPID__`…`__DOUYIN_APPID_21__` 及对应 `__DOUYIN_SECRET__` / `__SIGN_SALT__` | 抖音小程序（多个应用） | 抖音开放平台 |
| `__BILI_APPID__`…及 `__BILI_SECRET__` | B站小程序（多个应用） | 哔哩哔哩开放平台 |
| `__JWT_SECRET__` | APP 端 JWT 加密密钥 | 自定义任意随机串 |

### application-dev.yml / application-prod.yml / application-app2.yml（数据库/Redis）
| 占位符 | 含义 |
|---|---|
| `__RDS_MYSQL_HOST__` | 生产 MySQL 主机 |
| `__RDS_REDIS_HOST__` / `__REDIS_HOST__` | Redis 主机 |
| `__DB_NAME__` | 数据库名（导入 `db/duanju_yizhao.sql` 后填实际库名） |
| `__DB_USERNAME__` / `__DB_USERNAME_2__` | 数据库用户名 |
| `__DB_PASSWORD__`…`__DB_PASSWORD_5__` | 数据库 / Redis 密码 |

> dev 默认连本地 `127.0.0.1:3306/duanju_dev`，本地开发只需改密码。

> 注：`uniapp` 中 `plugin-private://wx94a6522b1d640c3b`（微信视频播放插件 provider）为公共固定 ID，**未替换**，保持原样即可。

## 二、数据库中的配置项（`common_info` 表）

导入 `db/duanju_yizhao.sql` 后，`common_info` 表里以下行的 `value` 为占位符，需在后台或直接改库填入：

| 占位符 | 含义 |
|---|---|
| `__WX_APPID__` / `__WX_SECRET__` / `__WX_TOKEN__` / `__WX_AESKEY__` | 微信小程序（后台读取用） |
| `__WX_APPID_2__` / `__WX_SECRET_2__` | 第二个微信小程序 |
| `__UMENG_PUSH_APPKEY__` / `__UMENG_PUSH_APPID__` / `__UMENG_PUSH_MASTERSECRET__` | 友盟 APP 推送 |
| `__OSS_ACCESS_KEY_ID__` / `__OSS_ACCESS_KEY_SECRET__` | 阿里云 OSS |
| `__SMS_ACCESS_KEY_ID__` / `__SMS_ACCESS_SECRET__` | 阿里云短信 |
| `__WXPAY_API_KEY__` / `__WXPAY_MCH_ID__` | 微信支付 |

## 三、数据库初始化

```bash
mysql -uroot -p -e "CREATE DATABASE duanju_yizhao CHARACTER SET utf8mb4;"
mysql -uroot -p duanju_yizhao < db/duanju_yizhao.sql
```

包含：全部 72 张表结构 + 基础配置/字典数据。用户、登录 token、授权、消息等业务表仅含结构不含数据。
