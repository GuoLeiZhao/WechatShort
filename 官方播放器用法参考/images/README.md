# 图片资源说明

## TabBar 图标
需要准备以下图标文件（建议尺寸：81px × 81px）：

- `theater.png` - 剧场图标（未选中状态）
- `theater-active.png` - 剧场图标（选中状态）
- `profile.png` - 我的图标（未选中状态）
- `profile-active.png` - 我的图标（选中状态）

## 页面图标
以下图标用于页面内显示（建议尺寸：40px × 40px）：

- `search.png` - 搜索图标
- `more.png` - 更多操作图标（三个点）
- `settings.png` - 设置图标
- `id.png` - ID 图标
- `message.png` - 消息中心图标
- `history.png` - 观看历史图标
- `service.png` - 客服图标
- `help.png` - 帮助中心图标
- `feedback.png` - 意见反馈图标
- `arrow-right.png` - 右箭头图标

## 占位图片
页面中使用的海报图片为占位符，实际使用时需要替换为真实的剧集海报图片。
